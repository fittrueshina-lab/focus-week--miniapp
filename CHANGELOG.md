# FOCUS Mini App — журнал изменений

## 1.8.1 — 24 ноября 2026

**Добавлено:** Telegram SDK, POST сохранения и чтения истории, подтверждение сервера, повтор отправки с тем же ID, локальное хранение по Telegram ID. Формат 11 пунктов и комментария сохранён. Старый общий локальный архив не переносится автоматически во избежание смешивания аккаунтов. Синтаксис inline JS проверен; CORS, авторизация и реальная запись требуют теста в Telegram. Commit: 98a53b343b0ff6a825c3a26afdb0f14e7553756a.

## 1.8.0 — 24 ноября 2026

**Изменено:** прямой доступ SpreadsheetApp вместо service account; восстановлены 19 столбцов, история по Telegram ID и расчёт недель. Чтение истории только POST, без JSONP в URL. Исправлена HMAC-проверка. По умолчанию сохранён ID старой таблицы, переопределяется SPREADSHEET_ID; заголовки проверяются до записи. Требуется подтвердить целевую таблицу, проверить доступ, клиентский протокол и выполнить живые тесты. Commit: 174b64663f84958019dcedeaec2ed2a98ff69866.

## 1.7.2 — 24 ноября 2026 (архив, без изменения рабочего кода)

**Добавлено:** резервная копия старого Apps Script в `backups/2026-11-24/Code.gs`, полученная от владельца. Сохранены исходные функции истории, недель и 19 столбцов. Архив не предназначен для публикации. Содержимое сверено после записи с подготовленным текстом; оригинальный редактор недоступен. Commit: cbd06a22e266355d4bb23c80ca46d4315cfb3b74.

## 1.7.1 — 24 ноября 2026

**Исправлено:** при HMAC-проверке Telegram исключается только hash; строка проверки преобразуется в байты для вызова Utilities.computeHmacSha256Signature с бинарным ключом.

**Файл:** backend/Code.gs. **Commit:** afe6fa83801d8d5359915bb51db3d6e962e5a768.

**Статус:** изменения проверены статически, живой тест и публикация ещё не выполнены. Клиентская интеграция не изменена.

## 1.7.0 — 15 ноября 2026

**Добавлено:** подготовлен приём недельных отчётов в Google Таблицу `FOCUS — недельные отчёты участников` с 11 ответами и отдельным комментарием.

**Изменено:** серверный код `backend/Code.gs` теперь использует ID созданной таблицы по умолчанию (его можно переопределить в Script Properties).

**Исправлено:** повторная отправка с тем же `requestId` не создаёт дубль даже после истечения кеша: идентификаторы записываются в столбец O; срок действия подписи Telegram ограничен одним часом.

**Статус:** код сохранён в GitHub. Автоматическая отправка из интерфейса ещё не включена: сначала нужно развернуть именно этот серверный код в Google Apps Script, установить `TELEGRAM_BOT_TOKEN` в Script Properties и получить URL `/exec`. Не размещать токен в GitHub. Для уже открытого старого Apps Script требуется заменить код, а не просто нажать «Развернуть».

**Commit:** `5ce51338fcfe2e14ad88fc4f94b083344d869350` — `fix(focus): v1.7.0 durable deduplication and configured report sheet`.
